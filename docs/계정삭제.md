# 가화만사성 계정 및 데이터 삭제

가화만사성 계정을 삭제하면 앱 서버에 있는 프로필, 가족·지인, 운세 기록, 추가 질문, 재화 기록이 함께 삭제됩니다. 삭제한 내용은 복구하지 않습니다.

## 앱에서 삭제

1. 가화만사성 앱을 엽니다.
2. 구글 계정으로 로그인합니다.
3. 오른쪽 위 설정을 누릅니다.
4. **계정 탈퇴**를 누르고 확인합니다.

## 앱을 지운 뒤 삭제 요청

앱을 이미 삭제했다면 jadissproject@gmail.com 으로 메일을 보냅니다.

- 제목: 가화만사성 계정 삭제
- 본문: 가입에 사용한 구글 계정 이메일

메일을 확인한 뒤 해당 계정의 서버 데이터를 삭제합니다.

구글플레이가 보관하는 결제 기록은 구글 계정 정책에 따릅니다.
